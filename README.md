# 🌟 Orion - AI Business Intelligence Dashboard

A beautiful, ChatGPT-style AI-powered business intelligence assistant built with Next.js 14 and optimized for Vercel deployment.

![Next.js](https://img.shields.io/badge/Next.js-14.2.5-black)
![React](https://img.shields.io/badge/React-18.3-blue)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-38bdf8)

## ✨ Features

- 💬 **Interactive AI Chat Interface** - ChatGPT-like experience for business queries
- 📊 **Real-time KPI Dashboard** - Track revenue, customer growth, and conversion rates
- 🎨 **Modern Dark Theme** - Professional, eye-friendly interface
- 📱 **Responsive Design** - Works perfectly on desktop and mobile
- ⚡ **Zero Configuration** - Deploy directly to Vercel
- 🚀 **Lightning Fast** - Optimized with Next.js 14

## 🚀 Quick Start

### Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Deploy to Vercel

```bash
npm run build
```

See [DEPLOYMENT.md](./DEPLOYMENT.md) for detailed deployment instructions.
